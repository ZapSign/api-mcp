## OAuth library choice + rationale

**Choice: narrow façade with KvStore (src/node/oauth/)**

oidc-provider was evaluated and REJECTED for these reasons:
1. Cannot express Client ID Metadata Documents (CIMD) — MCP auth spec 2026-07-28
   requires CIMD at the registration endpoint GET path; oidc-provider serves
   a full OpenID Connect discovery document but has no concept of CIMD.
2. Designed for full-stack AS with persistent sessions; MCP needs stateless
   per-request dispatch.
3. Would force a completely different middleware stack (Koa/Express), conflicting
   with the node:http requirement.

The narrow façade in src/node/oauth/ replicates exactly what workers-oauth-provider
did for MCP: DCR (RFC 7591), PKCE S256, CIMD, resource metadata, token exchange.
No jose JWT signing needed — tokens are opaque strings stored in DynamoDB via KvStore.

## Build

npm run build:node
  → dist/node/main.js  (252 KB)
  → dist/node/main.js.map

Boot command:
  node --import ./src/node/cf-shim.mjs dist/node/main.js

The cf-shim.mjs ESM hook stubs cloudflare:workers (imported by agents/mcp at module
load time) with a data: URI shim. This is the canonical approach for Node servers
that consume libraries also targeting Cloudflare Workers.
